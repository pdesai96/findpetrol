# Local Fuel Finder

I want to build a simple 1 page site where I can see the cheapest petrol prices around me. I want to be able to search by town name or I should be able to click “current location” and it should find the cheapest petrol prices around me. On the page, I’d like to see the petrol price itself.

This project was built with [Lovable](https://lovable.dev).
